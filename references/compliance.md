# 合规与风控边界（必须遵守）

> 本工具定位：**内部提效**——把「人工逐条复制粘贴」变为「批量下载得更快」。
> 数据仅限内部线索筛选使用，**不对外传播、不转售、不做二次分发**。

## 1. 法律与协议约束

- 外贸通的高管联系方式属于**会员付费墙后数据**，其用户协议通常禁止自动化批量抓取与二次导出。
- 批量抓取个人信息用于商业用途涉及《个人信息保护法》。
- **使用边界**：仅用于内部线索筛选，控制规模与频率，不转售、不公开、不喂给第三方。

## 2. 反爬 / 风控规避策略（避免封号）

外贸通（waimao.office.163.com）具备：登录态校验 + 设备指纹（`pass_2fa`/`_deviceId`/`_sDeviceId`）+ 行为检测 + 滑块验证码。

| 措施 | 实现 |
|---|---|
| 拟人节奏 | 列表页间随机延时 2~5s；详情页间随机 3~6s；正态抖动而非固定间隔 |
| 日上限 | 每日最多 N 页 / M 条（默认 N=10 页、M=200 条，可调），到顶自动停止 |
| 失败退避 | 网络错误重试 ≤3 次，指数退避（2s/4s/8s）；429/滑块出现立即停止当日任务 |
| 指纹一致 | 固定 UA + 持久化 profile（同一设备指纹），不频繁换 IP/UA |
| 不逆向签名 | `sign` 由前端 webpack 内生成，**不破解**，全程在已登录页面内由页面自身发请求，行为等同人工 |
| 会话失效 | 收到 401/403 判定 Cookie 失效，停止并提示重新登录，不死循环刷请求 |
| 工作时间 | 建议仅在正常工作时段运行，避免凌晨高频 |

## 3. 风控熔断规则

- 连续 3 次请求失败 → 暂停 10 分钟再试一次，仍失败则当日停止。
- 出现滑块/验证码 → 立即停止，转人工处理，不尝试绕过。
- 触发任何账号警告 → 停止并保留现场日志。

## 4. 数据安全

- `data/storage_state.json`、`data/*.csv` 含敏感登录态与个人信息，**禁止提交版本库、禁止外传**。
- `.gitignore` 必须包含 `data/`、`.profile/`。
